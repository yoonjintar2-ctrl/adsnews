# 4컷 만평 작법 — 재미있게 (발행인 11/17: "만평은 진짜 재미없어 좀 학습해서 해봐")

## 지금까지 왜 재미없었나 (11/13~17 진단)
- **기사 줄거리를 4컷으로 다시 말하기만 했다.** 1컷 상황 → 2컷 기사 내용 → 3컷 약한 반응 → 4컷 교훈 한마디. 독자는 이미 아는 얘기를 한 번 더 봤다.
- **웃음을 미리 설명했다.** 예: 11/17 2컷 "노이즈 캔슬링도 켜야지" → 3·4컷 반전(버스를 놓침)이 미리 다 보였다.
- **4컷째가 교훈이나 감상으로 끝났다.** "…그래도 귀는 따뜻하다", "다음 조합은 누가 먼저 찍을까" 같은 정리 멘트는 웃음이 아니라 해설이다.
- **인물이 매일 바뀌어** 캐릭터로 웃길 틈이 없었다(민재·하준·지우·하늘·도윤…).
- **대사가 길고 많다.** 컷마다 두 줄, 설명조.

## 원칙
1. **아이디어 먼저, 기사 요약 나중에.** "이 이슈에서 제일 웃긴 모순·과장·엉뚱한 결과는 뭐지?"를 한 줄로 먼저 쓴다. 그 한 줄이 재미없으면 그림을 그리지 않는다.
2. **후보 5개 → 1개.** 매일 아래 기법 중 서로 다른 것으로 웃음 후보 5개를 한 줄씩 쓰고, 가장 의외인 것 하나를 고른다(나머지는 원고 JSON의 `gag.candidates`에 남긴다).
3. **4컷의 역할(기·승·전·결):**
   - 1컷 **기**: 누가, 어디서인지가 그림만 봐도 보이게. 대사는 짧게, 설명하지 않는다.
   - 2컷 **승**: 기대를 쌓는다. 독자가 "이렇게 되겠지" 하고 예상하게 만든다(복선은 그림 속 소품으로 슬쩍).
   - 3컷 **전**: 한 박자 쉬기. 긴장이 최고조인데 아직 터지지 않는다(멈춤, 표정, 무언).
   - 4컷 **결**: 예상을 뒤집는다. **15자 이내 한 마디 또는 대사 없는 그림 한 장.** 교훈·정리·감상은 금지.
4. **웃음을 설명하지 않는다.** 4컷에서 터질 것을 1~3컷 대사로 말하지 않는다. 복선은 말이 아니라 그림(소품·표정)으로.
5. **대사는 짧게.** 컷당 말풍선 2개 이하, 한 줄 25자 이하. 소리 내어 읽어 보고 걸리면 자른다. 같은 말을 반복하지 않고 새 정보를 더한다.
6. **고정 출연진** — 인물이 낯익어야 반 박자 빨리 웃는다. 특별한 이유가 없으면 이 셋 중 둘로 쓴다(광고늬우스 편집국 사람들):
   - **최신상 사원**(잘파 신입): 유행을 제일 먼저 알고 과하게 실천한다. 말투는 짧고 신조어. 회색 후드, 짧은 머리.
   - **금로동 과장**(미디어 17년차): 진지하고 옛날 방식, 숫자와 매체 얘기로 받아친다. 결국 제일 크게 빠져든다. 안경, 니트 조끼.
   - **안광주 대리**(AE): 늘 광고주 전화에 시달리고, 모든 걸 "그거 광고주한테 팔 수 있어?"로 본다. 정장, 손에 휴대폰.
   (이슈상 소비자·가족이 꼭 필요하면 출연진이 '소비자로서' 겪는 일로 바꿔 본다.)
7. **실존 인물·브랜드 조롱 금지, 약자 조롱 금지.** 풍자는 상황·업계 관행·우리 자신을 향한다.

## 웃음 기법 (후보 5개는 서로 다른 기법으로)
| 기법 | 방법 | 예 (이슈: 헤드폰이 겨울 패션템) |
|---|---|---|
| 과장 | 이슈를 터무니없는 크기로 키운다 | 귀마개 대신 헤드폰을 쓰다 못해 스피커를 머리에 이고 출근 |
| 문자 그대로 | 비유·광고 문구를 진짜로 받아들인다 | "소음을 지운다"더니 과장의 잔소리까지 지워져 승진 |
| 역할 뒤집기 | 기대되는 사람과 반대 사람이 빠진다 | 질색하던 금 과장이 제일 큰 헤드폰을 쓰고 나타남 |
| 대가 | 좋은 점의 뒤통수를 친다 | 노이즈 캔슬링 덕에 버스 도착 소리를 못 들음 |
| 반복 후 깨기 | 같은 일 두 번 → 세 번째에 어긋남 | 셋이 차례로 헤드폰을 씀 → 넷째 칸엔 귀마개 쓴 강아지 |
| 업계 자조 | 광고인들끼리만 아는 아픈 데 | 안 대리: "광고주가 헤드폰 쓰고 피드백 안 들음" |
| 침묵 컷 | 4컷째 대사 없이 그림 하나로 | 눈 덮인 정류장, 헤드폰만 따뜻하게 김이 남 |

## 스스로 점검 (원고 반영 전에 꼭)
- [ ] 기사 안 읽은 사람이 4컷만 보고 웃을 수 있나? 한 줄로 설명할 수 있나?
- [ ] 4컷째를 가렸을 때 독자가 결말을 맞힐 수 있나? → 맞히면 다시 쓴다.
- [ ] 1~3컷 대사에 4컷째 반전의 단서가 말로 나와 있나? → 지운다.
- [ ] 4컷째가 교훈·감상·정리로 끝나나? → 다시 쓴다.
- [ ] 지난 7일 만평과 같은 구조인가(예: '기대 → 허탈한 혼잣말')? → 다른 기법으로.
- [ ] 아래 '좋은 예'만큼 웃긴가?

## 좋은 예 / 나쁜 예 (11/17 헤드폰)
나쁜 예(실제 실린 것): 1 "귀 안 시려요?" "헤드폰이 요즘 겨울 패션템이래요." / 2 "노이즈 캔슬링도 켜야지." / 3 "버스 왔어요!" (안 들림) / 4 "…그래도 귀는 따뜻하다."
→ 2컷에서 반전을 설명했고, 4컷이 감상이다.

좋은 예(같은 그림): 1 도윤 "귀 떨어지겠다…" 수아(헤드폰) "네? 뭐라고요?" / 2 도윤(거울) "따뜻한데 조용하기까지." / 3 수아 "버스!! 버스!!!" 도윤(평온) / 4 도윤 "…저거 내 버스?"
→ 1컷의 "네? 뭐라고요?"가 '안 들린다'는 복선을 말없이 심고, 4컷은 6자 한마디로 뒤집는다.

## 원고 JSON에 더할 칸
```json
"gag": {"technique": "대가", "premise": "따뜻함을 샀더니 세상 소리를 못 듣는다",
        "candidates": ["과장: …", "문자 그대로: …", "역할 뒤집기: …", "업계 자조: …"]}
```
ingest_grok.py가 4컷째 길이(15자), 대사 길이(25자), 컷당 말풍선(2개), 교훈형 끝맺음 낱말을 검사한다.
